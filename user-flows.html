01

Request a sample box

The primary conversion path. A visitor discovers a surface, checks the specification, builds a box of up to five samples and sends a request.

7 steps · 5 screens
  1. 01Browse the libraryOpen Explore from the tab bar or the home search field.Explore
  2. 02Open a surfaceTap a material card to see the full specification.Material detail
  3. 03Choose a finishHoned, polished, brushed or natural — the note updates.Material detail
  4. 04Add to sample boxLimit five. The tab badge and header count update instantly.Sample box
  5. 05Review the boxRemove, compare and add a recommended surface.Sample box
  6. 06Enter delivery detailsName, email, project type and address are required.Request samples
  7. 07ConfirmationReference number, surface count and delivery window.Request confirmed

Entry points

  • Home hero card and “Curated for you” rail
  • Explore tab, family chips and filter sheet
  • Search results and moodboard “View surface”

Edge cases

  • Empty box → browse prompt, request CTA disabled
  • Five surfaces → sixth add is blocked with a toast
  • Invalid form → inline focus on the first missing field
  • Box emptied mid-flow → returned to the sample box
02

Search & save a surface

A returning trade client knows roughly what they want. The path optimises for speed: search, open, save, collect into a project moodboard.

5 steps · 4 screens
  1. 01Start a searchSearch screen opens with recents, families and trending surfaces.Search
  2. 02Scan resultsResults show family, origin and finish — tap to open.Search
  3. 03Verify the surfaceRead the specification and pick the finish for the project.Material detail
  4. 04Save itThe heart fills, the toast confirms, the studio count rises.Material detail
  5. 05Collect the schemeSaved surfaces wait in the moodboard; tap + to add one to the board.Moodboard

Entry points

  • Home search field or ⌘K / Ctrl K
  • Search icon in the Explore header
  • Guided journey 02 from the presentation rail

Edge cases

  • No results → suggest broader terms and families
  • Empty query → recents and trending restore
  • Clearing the query keeps the user on Search
  • Saved state persists in local storage
03

Book a consultation

For clients who need guidance before specifying. A short, gated booking flow that only enables confirmation once a date and time are chosen.

6 steps · 3 screens
  1. 01Discover the advisorStudio card or home consultation card introduces the visit.Studio
  2. 02Open bookingAdvisor, location and duration are confirmed up front.Book a visit
  3. 03Choose a dateSeven-day strip; the selected day inverts to ink.Book a visit
  4. 04Choose a timeUnavailable slots are struck through and disabled.Book a visit
  5. 05Pick a formatStudio, video or site visit — the CTA label updates.Book a visit
  6. 06ConfirmationDate, time, format and advisor in a summary card.Consultation confirmed

Entry points

  • Home “Book a consultation” card
  • Studio quick action and presentation journey 03
  • Material detail note for specification advice

Edge cases

  • No date or time → CTA disabled, never a dead end
  • Unavailable slot → not selectable
  • Notes field optional, never blocks confirmation
  • Back from confirmation returns to the booking screen

Tested interactions

Navigation and state were verified across desktop, tablet and mobile widths before refinement.

✓
Screen navigation & back stack

Tabs, detail pushes, back buttons and screen-index jumps all resolve to a valid screen.

✓
Sample box rules

Add, remove, five-surface limit, badge counts and empty state stay in sync.

✓
Search, filters & sort

Live query, family chips, sheet filters and four sort orders update the grid.

✓
Form validation

Required fields block submission; valid data produces a reference and summary.

✓
Booking gate

Confirmation stays disabled until both a date and a time are selected.

✓
Persistence & reset

Saved surfaces, samples and bookings survive refresh; reset restores the demo.

✓
Responsive behaviour

Presentation rails collapse at 1240 px; the phone becomes full-screen at 760 px.

✓
Accessibility

Focus styles, aria labels, dialog state, reduced-motion and Escape handling.
